𓂩 Deep Resonance Trance Portal

This is an instrument for sculpting immersive, modular audio-visual trance experiences. It is an anti-tool designed to explore generative art as a form of ontological rebellion, using computation to manipulate spacetime and enter resonant flow states.

Symbols & Controls

The interface uses symbols to represent actions (morphisms) and components (entities).

  • 𓉗 GLOBAL MODIFIERS: Controls affecting all layers simultaneously.
  • 𓈌 GLOBAL LFO: A system-wide oscillator to modulate parameters over time.
  • 𓃑 ADD LAYER: Creates a new, independent resonance field (an Entity).
  • ⌸ DRAG HANDLE: Grab this to reorder layers or nest one inside another (a Morphism).
  • 𓉚 / 𓉙 COLLAPSE: Shows or hides a layer's detailed controls.
  • BLEND MODES: Defines how a layer's visuals combine with those below it.
  • ⿴ IMPORT / EXPORT: Save or load the entire session state.
  • ⿻ FLOAT: Toggles the compact, draggable UI mode.
  • ▙▙▙ CONTROLS ▟▟▟: The main bar to hide or show the entire control panel.
